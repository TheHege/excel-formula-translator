# Формулы без возни · Excel EN ⇄ RU

Переводчик формул Excel с английского на русский и обратно. Один HTML-файл,
без установки, аккаунта, сервера и подключения к интернету.

Сделан из-за лени вручную менять названия функций, точки и запятые в лабах.

```text
=IF(COUNT(A1:A10)>0,1.5,"no data")
                     ⇅
=ЕСЛИ(СЧЁТ(A1:A10)>0;1,5;"no data")
```

## Запуск

1. Скачай проект через **Code → Download ZIP** и распакуй архив.
2. Открой **index.html** в современном браузере двойным кликом.
3. Вставь формулу слева и нажми **«Копировать формулу»** или **Ctrl+Enter**.

Перевод появляется автоматически. Кнопка **⇄** меняет направление и переносит
результат в поле ввода. Файл **Переводчик формул.html** — такая же автономная
версия с русским названием: любой из этих двух файлов можно переносить отдельно.

## Возможности

- Словарь на **459 имён функций**, включая статистику, поиск и условия.
- Перевод аргументов `, ⇄ ;` и дробей `1.5 ⇄ 1,5`.
- Перевод логических значений и распространённых кодов ошибок.
- Константы массивов: `{1.5,2;3,4} ⇄ {1,5\2;3\4}`.
- Сохранение строк в двойных кавычках, в том числе экранированных `""`.
- Сохранение имён листов в одинарных кавычках и содержимого квадратных скобок.
- Перевод нескольких формул: по одной в строке.
- Выбор десятичного разделителя русской стороны: запятая или точка.
- Предупреждения о неизвестных функциях, незакрытых кавычках и скобках.
- В обратном переводе принимаются русские имена функций с **Е** вместо **Ё**.

Формулы обрабатываются локально. Приложение не отправляет их на сервер,
не сохраняет в браузере и не подключает внешние скрипты или шрифты.

## Ограничения

Направление выбирается вручную; язык формулы автоматически не определяется.
Английская сторона использует десятичную точку и запятую между аргументами.
Русская — точку с запятой между аргументами и выбранный десятичный разделитель.
Для массивов русской стороны используются `\` между столбцами и `;` между строками.
Другие региональные настройки могут потребовать ручной корректировки.

Неизвестные функции сохраняются с предупреждением. Текст внутри кавычек,
включая аргументы `INDIRECT` и шаблоны `TEXT`, остаётся без изменений.
Содержимое структурированных ссылок в квадратных скобках также не локализуется.
Переводчик не вычисляет формулу и не добавляет отсутствующие функции в старый Excel.
Локальные функции LAMBDA с именами, совпадающими со встроенными, отдельно не разрешаются.
Максимальная длина одной формулы — 200 000 символов.

## Разработка

Для сборки нужен **Node.js 18+**. Внешних зависимостей нет; `npm install` не требуется.

```sh
node build.cjs
node test.cjs
```

Или `npm test`: он сначала собирает приложение, затем запускает проверки.
Сборка обновляет `index.html`, `Переводчик формул.html` и `dictionary.json`.

| Файл | Назначение |
| --- | --- |
| `core.js` | Разбор формулы и перевод в обе стороны |
| `app.js` | Поля, кнопки, направление, копирование |
| `template.html` | Интерфейс и стили |
| `functions.json` | Исходная таблица соответствий из справки Microsoft |
| `build.cjs` | Дополнения к словарю и сборка автономного HTML |
| `test.cjs` | Примеры перевода, обратный перевод, словарь и события интерфейса |

Проверки охватывают 39 примеров формул, переводы всех записей словаря в обе
стороны, дроби, массивы, кавычки, смену направления и пакетный режим.
События интерфейса проверяются с моделью DOM; визуальная проверка браузером
и проверка вычислений в самом Excel в эти тесты не входят.

## Источники

Основа словаря — сопоставление названий по общим ссылкам на функции в
[английской](https://learn.microsoft.com/en-us/office/dev/add-ins/excel/excel-add-ins-worksheet-functions)
и [русской](https://learn.microsoft.com/ru-ru/office/dev/add-ins/excel/excel-add-ins-worksheet-functions)
справке Microsoft, дополненное распространёнными и совместимыми функциями.
Проверки словаря подтверждают согласованность перевода; они не являются
независимой проверкой каждого названия в установленном Excel.

Это независимый проект. Microsoft Excel — товарный знак Microsoft.

## English

A single-file, offline English–Russian Excel formula translator. Converts function
names, separators, decimal marks, booleans, error codes and array constants in
both directions while preserving quoted strings and reference labels. Open
`index.html` in a modern browser; no installation or dependencies are needed.
